# Mes applis 🚀

Mes applis web, développées avec l'aide de Claude pendant que j'apprends à coder.

👉 **Le site : https://clemcode69.github.io/mesapplis/**

## Ajouter une appli

1. Créer un fichier `.html` à la racine du dépôt, par exemple `jeu-du-pendu.html`.
2. L'envoyer sur la branche `main` (*Add file* → *Upload files* → *Commit changes*).
3. Attendre une à deux minutes : l'appli est en ligne et apparaît sur la page d'accueil.

Conseils pour les noms de fichiers : minuscules, sans accents ni espaces, avec des tirets.

## Comment ça marche

- `index.html` : la page d'accueil, qui liste automatiquement les applis.
- `.github/workflows/pages.yml` : publie le dépôt sur GitHub Pages à chaque modification de `main`.

Si une appli n'apparaît pas, regarder l'onglet **Actions** : une coche verte veut dire que la publication a réussi.

⚠️ Ce dépôt est public : ne jamais y mettre de mot de passe, de clé d'API ou d'information personnelle.
